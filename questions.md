# Questions for the Q1 knowledge graph

Q1 (Hölker et al. 2021): How to harmonize light measurement methods across disciplinary boundaries?

## Questions the graph should answer

1. Which measurement methods are mentioned in ALAN papers from 2024-2026, and how often?
2. Which disciplines use which methods?
3. Which quantities does each method measure?
4. Which units report each quantity, and who reports them?
5. Which methods and units appear together in papers about harmonization or standardization?
6. How does the mention of each method change from 2024 to 2026?

## Expected answers (written before scanning)

Source: Dickerson et al. 2026, Tables 1 and 2. A starting test set, not the full truth.

- illuminance: lx, used by lighting engineers, policymakers, ecologists
- luminance: cd m-2, used by lighting engineers
- radiance: W m-2 sr-1, used by astronomers, visual ecologists
- irradiance: W m-2, used by biologists, ecologists
- photon irradiance: umol m-2 s-1, used by plant biologists, ecologists
- night sky brightness: mag arcsec-2, used by astronomers
- spectral irradiance / radiance (SPD): W m-2 nm-1, used by visual ecologists, biologists, lighting engineers
- lux meter measures illuminance
- Sky Quality Meter measures night sky brightness
- spectroradiometer measures spectral irradiance / radiance
- multispectral fish-eye camera measures radiance / luminance maps
- satellite sensors (VIIRS/DNB) measure upward radiance
